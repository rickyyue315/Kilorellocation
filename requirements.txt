# ── 執行期依賴（鎖定為已通過測試的版本，確保 Streamlit Community Cloud 部署與本機一致）──
# Python 版本：3.11–3.14 皆可（Community Cloud 目前預設 3.14）。
#
# 版本選擇說明（v2.38.2）：
#   streamlit 1.51 以前限制 pyarrow<22，而 pyarrow 21 沒有 cp314 wheel（僅 cp39–cp313），
#   在 Python 3.14 上會退回原始碼編譯 Arrow C++ 而失敗（容器無 cmake）。
#   → streamlit 1.52 起移除 pyarrow 上限，故升級至 1.52.2 並鎖定 pyarrow==22.0.0
#     （提供 cp310–cp314 wheel，任何受支援的 Python 版本都能直接安裝 wheel）。
#   → altair 依 Python 版本分流（v2.38.4）：
#     altair 5.5.x 的 schema 以 class X(TypedDict, closed=True) 定義，且版本守衛寫成
#     「Python >= 3.14 就改用內建 typing.TypedDict」；但 3.14 的 typing.TypedDict 尚未支援
#     PEP 728 的 closed，匯入時即拋 `_TypedDictMeta.__new__() got an unexpected keyword
#     argument 'closed'`（圖表步驟整個失敗）。altair 6.x 的守衛是 >= 3.15，可正常運作，
#     故 3.14 一律用 6.x，3.13 以下維持已驗證的 5.5.0。
